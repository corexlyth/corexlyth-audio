# corexlyth-audio
CoreXLyth Audio

CoreXLyth blogunda kullanılan arka plan müziklerinin barındırıldığı ses deposu.

Müzikler GitHub Pages üzerinden servis edilir ve CoreXLyth tema içindeki müzik motoru tarafından kullanılır.

Klasörler

- "phonk/" → Teknoloji, cyberpunk ve phonk temalı içerikler
- "history/" → Tarih, belgesel ve orkestral içerikler

İleride yeni müzik havuzları eklendikçe yeni klasörler oluşturulabilir.

CoreXLyth Music Tags

CoreXLyth, Blogger yazılarındaki gizli sistem etiketlerini okuyarak uygun müzik listesini seçer.

Örnekler:

"_music_phonk"

"_music_history"

Bu etiketler ziyaretçilere gösterilmez; yalnızca tema tarafından müzik havuzunu belirlemek için kullanılır.

GitHub Pages

Kaynak ve Lisanslar

Kullanılan parçaların sanatçı, kaynak, Pixabay ID ve lisans bilgileri:

"SOURCES.md"

Yeni müzik eklendiğinde kaynak bilgisinin de "SOURCES.md" dosyasına eklenmesi önerilir.
